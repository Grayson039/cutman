# Cutman 🥊

> One app. Every promotion. All the fights.

A personal combat sports dashboard that aggregates fight cards, news, results, fighter stats, and broadcast information from across the web into one clean mobile interface.

No more bouncing between UFC.com, ESPN, Google, Reddit, and Tapology just to find out when the next fight is and where to watch it.
